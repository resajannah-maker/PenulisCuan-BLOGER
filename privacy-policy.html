Kebijakan Privasi

Kami sangat menghargai privasi pengunjung blog ini. Halaman Kebijakan Privasi ini menjelaskan jenis informasi pribadi apa yang dikumpulkan dan dicatat oleh situs kami serta bagaimana kami menggunakannya.

File Log

Seperti banyak situs web lain, blog ini menggunakan file log. File-file ini hanya mencatat pengunjung ke situs—prosedur standar bagi perusahaan hosting dan bagian dari analitik layanan hosting.

Cookie dan Web Beacon

Blog ini menggunakan cookie untuk menyimpan informasi preferensi pengunjung. Pihak ketiga seperti Google (melalui AdSense) menggunakan cookie untuk menayangkan iklan berdasarkan kunjungan pengguna ke situs web ini dan situs web lainnya di internet.
